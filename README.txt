REVISTA DIGITAL — ENEM DO ARNALDO 2026

1. Abra esta pasta no VS Code.
2. Abra index.html.
3. Para visualizar: instale a extensão Live Server no VS Code e clique em "Go Live".
   Também é possível abrir index.html diretamente no navegador.
4. Use as setas, os botões Anterior/Próxima ou Tela cheia.

Arquivos:
- index.html: conteúdo e páginas
- style.css: aparência e responsividade
- script.js: navegação e tela cheia
- assets/: imagens da revista
